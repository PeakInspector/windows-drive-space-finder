# Contributing

Thanks for the interest. This is a small free tool, so the bar is simple.

- Bug reports: open an issue with your Windows version and the folder Shed mislabeled.
- Rules: the plain-words rules live in the open rules file; a wrong rule is a one-line fix in a pull request.
- Design and docs: the mockup sources live in `design/` and render with Node 20 (`npm install`, `node render.mjs all`).

By contributing you agree your contribution is MIT-licensed. No bundled installers, no upsells — keep it that way.
